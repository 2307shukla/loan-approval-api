# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
open the **Security** tab of this repository and choose **Report a vulnerability**. You will get a reply
as soon as possible; please include steps to reproduce and the affected version or commit.

## Scope and practices

- Only the latest code on the `main` branch is maintained.
- No secrets are stored in this repository; configuration comes from environment variables.
- Dependencies are kept to permissively licensed libraries.
- This is a portfolio project: the live demo runs on free hosting and holds only demo data.
